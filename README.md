# Roman Pelevin

Founder of [Neura](https://www.neurarelay.com) — the authority and evidence layer for consequential AI actions.

Neura sits between an agent’s proposed action and execution:

`proposed action → authority decision → execute or restrain → Decision Receipt`

I work with organizations and builders that need high-impact agent actions to be explicitly authorized, bound to the exact target, and independently verifiable.

- **[Build with Neura](https://www.neurarelay.com/builders)** — run a local check and connect an agent runtime.
